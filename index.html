// ABOUT //

A love letter to 25¢ nostalgia.

Old School Games is a growing collection of browser remakes paying tribute to the arcade and home-computer classics — Bomberman, Snake, Tetris, Pac-Man, Space Invaders, and more to come.

Every game is hand-built from scratch in pure HTML5 + canvas + vanilla JS. No engines, no trackers, no in-app purchases. Just the same games you played in the 80s and 90s — running natively in any modern browser, no install required.
